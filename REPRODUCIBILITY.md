# Reproducing CASL and rebuttal experiments

Run legacy CASL and rebuttal commands from the repository root. Historical scripts
expect this directory to be named `Asyrp_SAE`, with baseline source directories
beside it. On a fresh clone:

```bash
git clone --branch cleanup/reproducibility https://github.com/Zhenghao-He/H_SAE.git Asyrp_SAE
cd Asyrp_SAE
python tools/restore_layout.py
```

`reproduction/dependencies.json` records dependency commits, upstream remotes,
and local changes. Source snapshots include the locally modified baseline code;
they are ordinary files, not empty nested Git repositories. Preserve their
upstream licenses. `reproduction/` also contains the original DiT experiment
scripts that previously lived outside this Git repository.

## Data and checkpoints

Raw image datasets and their tar/zip copies were removed at the owner's request.
Dataset loaders, attribute labels, test manifests, and splits are retained.
Reacquire CelebA/CelebA-HQ, FFHQ, LSUN-Church, and AFHQ-Dog from their original
providers under their respective terms. Put them at the paths in
`configs/paths_config.py`, or update that file and the relevant experiment YAML.
The FFHQ downloader and AFHQ acquisition scripts are in the dependency snapshots.
The CelebA-HQ mapping and labels are in `reproduction/data_metadata/CelebA-HQ/`.
Datasets cannot be reconstructed from generated results or activation caches.

Expensive artifacts are archived at `/bigtemp/wff7ad/h_SAE/`, mirroring their
original directory layout. Each migrated file has a SHA-256, byte count, source,
and destination in `audit/migration.jsonl`. Original local paths are symlinks.
To reconnect a fresh clone to this archive:

```bash
python tools/restore_layout.py --archive /bigtemp/wff7ad/h_SAE
```

Remaining generated images are grouped into tar archives to reduce shared-disk
metadata overhead. Add `--images` to the command above to extract them. Their
counts and SHA-256 checksums are in `audit/image_archives.jsonl`; each tar was
compared against its source files before those copies were removed.

The archive includes diffusion/SAE/alignment weights, evaluation classifiers,
inversion and activation caches, and generated evidence. It is private storage,
not part of the GitHub checkout. On another machine, copy the relevant archive
subtrees and manifest, then pass that location with `--archive`. Dependency
download instructions remain in their upstream READMEs. Some historical SDXL
configs reference `/tmp/casl_sdxl`; inspect `work_dir` before resuming. Caches that
no longer exist must be regenerated by the corresponding collect/train stage.

Keep legacy and modern SDXL environments separate. Legacy dependencies are in
`requirements.txt`; modern dependencies are in `sdxl_rebuttal/requirements.txt`.
Dependency snapshots retain their own environment/requirements files. Historical
launchers contain server-specific Python paths and CUDA device choices; adjust
those to your environment. Reuse the recorded image IDs, seeds, strengths,
reference reconstructions, and classifier checkpoints for a numerical comparison.

The cleanup preserves failed runs and scientific caveats in reports and metrics.
In particular, the quick nonlinear-mapping ablation had weak target changes and
stochastic reconstruction differences; its deterministic rerun was not completed.
Archiving these files does not resolve that limitation or establish new results.

## Cleanup audit

`audit/worktree_before.patch` and `audit/status_before.txt` preserve the initial
working-tree state. `audit/deletions.jsonl` records disposable paths and removed
raw datasets. Dataset deletion is irreversible within this archive; reacquisition
is required. Source variants ending in `.backup`/`.broken` are retained under
`audit/old_scripts/`. Python bytecode and replottable charts are disposable.

The incomplete, syntactically invalid `evaluate_sae.py` draft was removed; its
original version remains in Git history and the initial working-tree backup.

The cleanup verifies source syntax, shell syntax where applicable, archived-file
checksums during transfer, Git payload size, and layout restoration. It does not
rerun GPU training after removal of raw datasets.
